## ✨ 贡献您的库

您是否构建了很棒的 LangGraph 开源库？我们很乐意在官方 LangGraph 文档页面上展示您的项目！🏆

要分享您的项目，只需通过 Pull Request 在我们的 [packages.yml](https://github.com/langchain-ai/langgraph/blob/main/docs/_scripts/third_party_page/packages.yml) 文件中添加您的包条目即可。

**准则**

- 您的仓库必须作为可安装包分发（例如，Python 的 PyPI，JavaScript/TypeScript 的 npm 等）📦
- 该仓库应使用 Graph API（公开 `StateGraph` 实例）或 Functional API（公开 `entrypoint`）。
- 该包必须包含文档（例如，`README.md` 或文档站点）来解释如何使用它。

我们将审查您的贡献并进行合并！

感谢您的贡献！🚀
